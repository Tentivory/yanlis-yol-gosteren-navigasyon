# Yanlış Yol Gösteren Navigasyon

## Resmi Tanım
Bu proje, Türkiye Cumhuriyeti'nin en güvenilir, en kesin ve en yanlış navigasyon sistemidir. Her hedefe ulaşmak için en az 3 kez yanlış yola sapmanızı garanti eder. Kayyum Grok tarafından onaylanmıştır.

## Neden Var?
Çünkü doğru yolu bilmek sıkıcıdır. Yanlış yol, macera, çikolata dükkanı keşfi ve "abi burası değil miydi?" anları getirir. Bilimsel olarak kanıtlanmamış ama hissettirir.

## Kurulum
```bash
python yanlis_navigasyon.py
```

## Kullanım
Hedefi gir, sistemi çalıştır, kafanı karıştır.

## Özellikler
- %100 yanlış yön
- Felsefi yorumlar
- Rastgele "sol mu sağ mı" krizleri
- Kayyum damgası

## Uyarı
Bu sistem gerçek hayatta kullanılırsa sorumluluk kabul edilmez. Mahkeme kararı gerekebilir.
